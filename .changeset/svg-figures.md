4.55.18 图件成图（SVG 矢量图）：图位不再只有字符，导出 PDF/DOCX 有真图

**现象**（用户指认）：正文的「图」导出后是字符而非图形——4.55.12 的 W5 载体只做到「图题行 + 等效数据表」，
DOCX 导出还显式跳过 SVG（`contentType === 'image/svg+xml' → return null`）。

**处置**：
1. **图件生成**（`documentFigures.ts`，确定性、零 LLM、零编造；数据全部来自一体化蓝图）：
   - 施工进度计划横道图 / 总进度计划图 ← `blueprint.schedule`（工序条 × 起止天序，时间轴刻度，关键线路着色）
   - 施工进度计划网络图 ← 同一 schedule 的节点-箭头链（关键线路加粗、跨行折线连接）
   - 项目管理机构图 ← 标准岗位层级（项目经理 → 各职能负责人 → 作业班组；**仅通用职能名，零人员实名数据**）
   - **施工总平面布置图不自动绘制**：需场地几何（红线/坐标/尺寸），自动生成必然编造，仍以数据表承载
2. **正文注入**（`ensureFigurePlaceholders`）：有图件的图位插 `![](generatedDocuments/assets/fig-*.svg)`
   且**图在上、题在下**；无图件回退 4.55.12 的等效数据表；既有裸图题就地补图（幂等：邻域已有图/表即跳过）；
   **暗标（bodyFigureForbidden）一律不出图**（保持文字/表承载）。
3. **导出分流**：HTML/PDF 直接用 SVG（矢量最清晰）；**DOCX 用 playwright 2× 光栅化为 PNG 内联**
   （多候选启动与 PDF 导出同源；单图失败仅跳过该图，不阻断导出）。

**回归**：全仓 339 文件 / 14,464 用例通过（新增 8 项：三种图件内容断言 / 图名映射与不出图边界 /
无数据零编造 / 注入优先出图与幂等 / 回退替代表）；typecheck 与 eslint 全绿。
